# Inbox Placement Test

> A free email-deliverability tool that reports where your email actually
> lands — Inbox, Spam, Promotions, or Not received — across 10 major
> mailbox providers: Gmail, Outlook (Microsoft 365 / Hotmail / Live), Yahoo Mail, iCloud Mail, AOL Mail, GMX, Web.de, T-Online, Mail.ru and Yandex. The user
> picks which providers to include (default: all 10); each selected
> provider contributes exactly one seed mailbox to the test. Results stream
> live via SSE and include full SPF/DKIM/DMARC diagnostics, Rspamd and
> SpamAssassin verdicts with rule breakdown, DNS-health checks (MX,
> PTR/FCrDNS, DNSBL), and a link checker for URLs found inside the message.
> No signup required. Ships with a REST API, an MCP server (for Claude /
> Cursor / other LLM clients), and an A2A-compatible Agent Card so AI
> agents can run inbox-placement tests programmatically.

Operator: Live Direct Marketing. Base URL: https://check.live-direct-marketing.online

## How the test works

- User submits their sender email address on the homepage.
- User picks which mailbox providers to test (Gmail, Outlook (Microsoft 365 / Hotmail / Live), Yahoo Mail, iCloud Mail, AOL Mail, GMX, Web.de, T-Online, Mail.ru and Yandex). One seed mailbox is generated per selected provider with a unique plus-addressing token (local+token@provider).
- User sends their test email to those seeds from their normal mailing system (ESP / SMTP).
- As each seed receives the message, the folder placement (Inbox / Spam / Promotions / Not received), auth results (SPF / DKIM / DMARC), spam-engine scores and per-URL link verdicts stream live to the results page via SSE.
- Tests complete within ~15 minutes; unreceived seeds are reported as Not received.
- Test records (placement + auth verdicts) are retained for 7 days, then auto-deleted. Subjects, senders and message bodies are never stored.
- Free-tier limit: 3 tests per email per day, 10 per IP per day.

## Interpreting single-provider tests

A green result from a single provider (e.g. Gmail only) does NOT mean overall deliverability is fine. Reputation is tracked independently by each ESP (Gmail / Microsoft / Yahoo / Mail.ru / Yandex / iCloud are separate systems). Gmail is the most lenient of the major providers — passing Gmail is the minimum bar, not a full deliverability signal. A partial test (fewer than 4 providers) is indicative only for the providers tested.
